## 🚀 Deploy to Coolify

### Step 1: In Coolify

1. **Create New Resource**
   - Click "+ New Resource" → "Docker Compose"

2. **Git Repository Configuration**
   - Repository: `https://github.com/Dgies1/n8n`
   - Branch: `unlocked-features`
   - Docker Compose Location: `docker-compose.coolify.yml`
   - Build Pack: `nixpacks` or `dockerfile` (if you add a Dockerfile)

3. **Configure Domain**
   - Add your domain: `n8n.yourdomain.com`
   - Enable HTTPS (Let's Encrypt)
   - Coolify will auto-set `SERVICE_URL_N8N`

### Step 2: Environment Variables

Coolify auto-generates most variables. You only need to verify/customize:

#### Auto-Generated by Coolify:
- ✅ `SERVICE_USER_POSTGRES` (auto)
- ✅ `SERVICE_PASSWORD_POSTGRES` (auto)
- ✅ `SERVICE_PASSWORD_ENCRYPTION` (auto - but you can override)
- ✅ `SERVICE_URL_N8N` (based on your domain)
- ✅ `IMAGE` (if building from Git)

#### Optional Customizations:

```env
# Timezone (optional, defaults to Europe/Berlin)
GENERIC_TIMEZONE=America/New_York
TZ=America/New_York

# Database name (optional, defaults to n8n)
POSTGRES_DB=n8n

# Security settings (defaults are fine, but you can customize)
N8N_BLOCK_ENV_ACCESS_IN_NODE=true
N8N_GIT_NODE_DISABLE_BARE_REPOS=true
N8N_ENFORCE_SETTINGS_FILE_PERMISSIONS=true
N8N_PROXY_HOPS=1
```

### Step 3: Deploy

Click "Deploy" and wait:
- First build: ~10-15 minutes (if building from Git)
- Services will start in order:
  1. PostgreSQL
  2. Redis
  3. n8n (main)
  4. n8n-worker

### Step 4: Access & Verify

1. Visit `https://n8n.yourdomain.com`
2. Complete initial setup
3. Check all services are healthy in Coolify logs

## ⚙️ How Queue Mode Works

With `EXECUTIONS_MODE=queue`:

1. **User triggers workflow** → n8n web process
2. **Workflow added to Redis queue** → Job queued
3. **Worker picks up job** → n8n-worker executes
4. **Results stored in PostgreSQL** → Job complete
5. **User sees results** → In web UI

**Benefits:**
- 🚀 Better performance (web stays responsive)
- 📈 Scalable (add more workers)
- 🛡️ Fault tolerant (workers can restart)
- 🔄 Long-running workflows don't block UI

## 📦 Backup & Restore

### Backup Database

```bash
# From Coolify server
docker exec <postgres-container-id> pg_dump -U n8n n8n > n8n-backup.sql
```

### Backup n8n Data Volume

```bash
docker run --rm \
  -v <project>_n8n-data:/data \
  -v $(pwd):/backup \
  alpine tar czf /backup/n8n-data-backup.tar.gz /data
```

### Restore

```bash
# Restore database
cat n8n-backup.sql | docker exec -i <postgres-container-id> psql -U n8n n8n

# Restore volume
docker run --rm \
  -v <project>_n8n-data:/data \
  -v $(pwd):/backup \
  alpine tar xzf /backup/n8n-data-backup.tar.gz -C /
```

## 🐛 Troubleshooting

### Worker Not Processing Jobs

Check:
1. Redis connection (worker logs should show connection)
2. Same `N8N_ENCRYPTION_KEY` across n8n and worker
3. Worker healthcheck is passing

### Database Connection Errors

Verify:
1. PostgreSQL healthcheck is passing before n8n starts
2. Credentials match (`SERVICE_PASSWORD_POSTGRES`)
3. Database `n8n` exists

### Redis Connection Issues

Check:
1. Redis healthcheck passing
2. `QUEUE_BULL_REDIS_HOST=redis` is set correctly
3. Redis container running

### Workflows Not Executing

1. Check worker is running and healthy
2. View worker logs for errors
3. Verify queue mode: `EXECUTIONS_MODE=queue`
